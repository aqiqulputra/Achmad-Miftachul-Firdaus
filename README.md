## 2. Gambaran Proyek

Website ini merupakan sistem portofolio digital profesional yang dirancang khusus untuk mendokumentasikan seluruh tahapan Praktik Pengalaman Lapangan (PPL) Mandiri mahasiswa PPG Universitas Negeri Malang di SD Laboratorium UM. 

Tema visual **Sports Education** memadukan estetika lintasan atletik, garis gerak geometris dinamis, palet warna elegan, dan tata letak editorial akademik modern untuk mencerminkan pendidik yang berkarakter, energik, komunikatif, dan reflektif.

### Palet Warna Resmi
* **Midnight Navy (`#14243A`):** Merepresentasikan kedalaman akademik, wibawa, dan stabilitas institusional.
* **Athletic Orange (`#F47738`):** Merepresentasikan antusiasme, energi olahraga, kreativitas gerak, dan aksentuasi fokus.
* **Warm White (`#F8F7F3`):** Latar belakang kanvas yang hangat, nyaman dibaca, dan kontras tinggi.
* **Graphite (`#303640`):** Tipografi isi berstandar aksesibilitas tinggi (WCAG AA).
* **Soft Green (`#6A8F78`):** Sentuhan keseimbangan alamiah, pertumbuhan karakter, dan kesehatan holistik.

## 5. Fitur Interaktif Unggulan

1. **Penampil Interaktif Google Drive (Live PDF Viewer & Modal):**
   Mendukung pratinjau langsung seluruh Modul Ajar, Lembar Refleksi LK (LK 3 & LK 4), dan Lembar Penilaian melalui Google Drive (`<iframe>` embed viewer) tanpa perlu mengunduh file. Jika link belum dilampirkan, sistem menampilkan placeholder elegan berstatus *"Slot Pratinjau Tersedia • Menunggu Tautan Google Drive"*.
2. **Integrasi Dokumen Refleksi Autentik Penuh (LK 3 & LK 4 Seluruh Siklus):**
   Memuat data evaluasi refleksi autentik lengkap mahasiswa: Praktik Mengajar Terbimbing (LK 3), Mandiri Siklus 1 (LK 4), Mandiri Siklus 2 (LK 4), Mandiri Siklus 3 (LK 4), dan Mandiri Siklus 4 (LK 4), lengkap dengan telaah apersepsi jembatan kognitif, kendala motorik siswa, efektivitas alat peraga, umpan balik Guru Pamong Anang Marzuqi, S.Pd., dan pengesahan DPL Prof. Yusuf Hanafi, S.Ag, M.Fil.I.
3. **Pencarian Real-Time (Live Search & Filter):**
   Memungkinkan penguji atau dosen pembimbing menemukan modul ajar, lembar observasi, atau siklus tertentu dalam hitungan detik. Tersedia juga shortcut keyboard `Ctrl + K`.
4. **Lightbox Galeri & Pemutar Video:**
   Pratinjau foto dokumentasi dilengkapi kontrol navigasi sebelumnya/selanjutnya, penomoran urutan, dan penutupan dengan tombol `Esc` atau klik di luar modal.
5. **Alur Kronologis (Timeline Component):**
   Visualisasi perjalanan PPL dari orientasi awal hingga refleksi final dengan indikator fase yang informatif.
6. **Navigasi Responsif Penuh (Mobile Drawer & Desktop Dropdown):**
   Pengalaman optimal di seluruh layar smartphone, tablet, laptop, layar resolusi tinggi, serta ramah cetak (*print-friendly*).

## 6. Panduan Menjalankan Website

Website dibangun menggunakan standar web murni (HTML5, Modern CSS3, Vanilla ES JavaScript) tanpa dependensi eksternal yang rumit, sehingga dapat dijalankan dengan beberapa cara mudah:

### Cara 1: Langsung di Browser (Offline / Standalone)
Cukup klik ganda (double-click) pada berkas `index.html` untuk membuka website langsung di browser apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Cara 2: Menggunakan Server Lokal Python
Jalankan perintah berikut di terminal/PowerShell pada direktori proyek:
```bash
python -m http.server 8080
```
Buka peramban di alamat: `http://localhost:8080`

### Cara 3: Menggunakan Node.js / npx
```bash
npx.cmd serve
```

## 7. Panduan Menambahkan Berkas PDF & Foto Asli

Untuk menyematkan file Modul Ajar atau Lembar Penilaian asli Anda:
1. Simpan berkas PDF Anda ke dalam folder `assets/docs/`
2. Beri nama berkas sesuai nama standar (lihat petunjuk di `assets/docs/README_DOKUMEN.txt`), misalnya:
   * `Modul_Ajar_Siklus_1.pdf`
   * `Rubrik_Penilaian_Siklus_1.pdf`
   * `Laporan_Observasi_Manajemen_SD_Lab_UM.pdf`
3. Perbarui status item pada `js/data.js` dari `"pending"` menjadi `"available"`.
4. Berkas secara otomatis dapat langsung dipratinjau dan diunduh oleh dosen penilai.
